                What Base64 is for
                
Turn text (or small binary) into a safe ASCII string for JSON, emails, or Basic Auth — and decode it back.

            

            
            
            

                
                
                
                
            

            

            
            
        

    


    

        

            

                What URL encode is for
                
A URL cannot contain spaces or most punctuation. Encoding turns hello world into hello%20world so you can safely put search text, names, or JSON into a query string or API path.

            

            
When you need it: building ?q=..., ?redirect=https://..., or copying a broken link from logs that looks like %2Flearn%2Fdsa. Encode before you send; decode to read it as a human.

            
            
            

                
                
                
            

            
            
        

    


    

        

            

                What timestamps are for
                
APIs and databases store time as a Unix number (seconds since 1 Jan 1970). This turns that number into a date you can read — and the other way around.

            

            
Unix → date: paste 1735689600 from a log, then click that button to see the calendar date.

            ISO → Unix: paste 2026-08-19T09:24:00Z from an API, then click to get the number to put in a query or DB.

            

                
                
                
                
            

            

            
            
            
            
            
            
            
            
        

    


    

        

            

                What UUID is for
                
Generate unique ids for database rows, request ids, or file names — without a collision with someone else’s id.

            

            
            
            

                
                
            

            
        

    


    

        

            

                What hashing is for
                
Get a fingerprint of text (checksum). Same input always gives the same hex; you cannot turn the hash back into the original.

            

            
            
            
            
            

                
                
            

            
            
        

    


    

        

            

                What regex is for
                
Test a pattern against sample text before you put it in Java, Python, or a log filter — see matches instantly.

            

            
            
            

                
                
                
                
            

            
            
            

                
            

            

            
            

        

    


    

        

            

                What cron is for
                
Read a scheduler expression like 0 9 * * 1-5 in plain English — useful for Jenkins, Kubernetes CronJobs, and Linux crontab.

            

            
            
            
Order is min hour date month weekday. Example: */15 * * * * = every 15 minutes. 0 0 * * 0 = Sunday midnight.

            

                
            

            

            

        

    


    

        

            

                What LLM tokens are for
                
Estimate how large a prompt or RAG chunk is before you hit the model. Helps you stay under context limits and guess API cost. This is an estimate (≈ 4 characters per token for English), not the official tokenizer.
