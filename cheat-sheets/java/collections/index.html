Collections & Concurrency

HashMap internals, concurrent collections, and thread safety — must-know for backend Java roles.

Interview tip HashMap: "Array of buckets → hash → index → linked list or tree if collision > 8 (Java 8+)."

Concurrency essentials

  • Thread vs Runnable: prefer Runnable/Callable + ExecutorService
  • synchronized: monitor lock — can deadlock
  • volatile: visibility only, not atomicity
  • ConcurrentHashMap: segmented locks / CAS — no full map lock
  • Atomic classes: AtomicInteger for counters
