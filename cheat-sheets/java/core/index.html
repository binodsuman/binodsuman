Java Core — Interview Cheat Sheet

OOP, JVM memory, and language fundamentals recruiters test on every Java interview.

Interview tip For "explain JVM" — draw heap vs stack, mention GC roots, then one collector (G1).

OOP pillars

ConceptInterview one-liner
EncapsulationHide state, expose via methods — data hiding
InheritanceIS-A — favor composition over inheritance
PolymorphismSame interface, different behavior — runtime via overriding
AbstractionInterfaces/abstract classes hide implementation

JVM memory model

Stack (per thread) — local vars, frames
Heap — objects, shared across threads
Metaspace — class metadata (post Java 8)
GC — mark-sweep, G1, ZGC for low latency
== vs equals: == compares references; equals() compares content (override for custom classes). Always override hashCode with equals.

String & immutability

String pool (intern), StringBuilder for loops (not + concatenation). Immutability = thread-safe, safe as hash keys.
