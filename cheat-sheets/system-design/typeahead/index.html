Design Typeahead / Autocomplete

Search suggestions as you type — prefix indexes, trie, and ranking at low latency.

Interview tip Target <100ms p99. Precompute top queries. Trie or Elasticsearch completion suggester. Cache hot prefixes.

Data prep

Aggregate query logs → top K suggestions per prefix. Periodic batch job refreshes. Filter NSFW / stale terms.

Query path

"appl"→ Cache→ Trie / ES→ Ranked list

Ranking signals

Popularity, personalization (optional), recency, prefix match quality.
