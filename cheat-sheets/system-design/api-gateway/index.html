Design API Gateway

Single entry point — auth, routing, rate limits, SSL termination, and observability.

Interview tip Gateway vs service mesh: gateway at edge; mesh for internal east-west. Mention Kong, AWS API GW patterns.

Responsibilities

  • Authentication / JWT validation
  • Rate limiting & quotas
  • Request routing to microservices
  • SSL, compression, request logging
  • Circuit breaker to unhealthy backends
