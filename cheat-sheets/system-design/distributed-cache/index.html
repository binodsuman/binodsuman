Design Distributed Cache

Redis cluster, consistent hashing, replication, and cache invalidation strategies.

Interview tip Explain sharding, replication for HA, cache-aside vs read-through, and thundering herd mitigation.

Why distributed

Single Redis hits memory limit. Shard by key hash across nodes. Each shard primary + replica.

Consistent hashing

Keys → hash ring → node. Add node = minimal key movement. Virtual nodes for balance.
