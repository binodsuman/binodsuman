ML & Deep Learning Interview Guide

Core concepts recruiters ask — with handwritten-style notes for quick revision before interviews.

Interview tip Always connect algorithm → use case → limitation. Example: "Random forest — tabular data, handles non-linearity, but slower inference than linear models."

Supervised learning essentials

AlgorithmWhen to useWatch out
Linear/LogisticBaseline, interpretableLinear boundaries only

SVMSmall data, kernelsBad on huge data
k-NNSimple, no trainingSlow at scale

Deep learning must-knows

  • Activation: ReLU fixes vanishing gradient; sigmoid for binary output
  • Batch norm: stabilizes training; different train vs inference behavior
  • Dropout: regularization — randomly zero neurons during training
  • CNN: parameter sharing + translation equivariance
  • Transfer learning: pretrained backbone + new head — always mention for limited data
